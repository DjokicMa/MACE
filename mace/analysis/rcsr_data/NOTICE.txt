3dall.txt.xz holds the Reticular Chemistry Structure Resource (RCSR) list of
3-periodic nets, unmodified, compressed with xz. MACE's topology analysis
(mace analyze topology, the GUI's Topology tab) matches nets against it.

Updating
  A newer list you import (mace analyze rcsr import 3dall.txt, or Import on
  the GUI's Topology tab) is used before this copy. To refresh the bundled
  copy, download the file again, compress it with xz, and update the date,
  sizes and checksums above (tests/test_rcsr_bundled.py checks them).
